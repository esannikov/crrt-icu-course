# Замісна ниркова терапія у ВІТ

Мобільний інтерактивний мінікурс українською для інтерна-анестезіолога. Курс охоплює рішення про початок ЗНТ, вибір між IHD, PIRRT/SLED і CRRT, судинний доступ, профілактику інфекцій, принципи терапії, водно-електролітний та кислотно-основний моніторинг і типові ускладнення.

## Що всередині

- 5 синтетичних дорослих пацієнтів на вибір;
- 8 модулів по 10 карток;
- миттєве пояснення після кожної відповіді;
- підсумковий рахунок і повторення помилок;
- збереження прогресу в браузері;
- адаптивний вебінтерфейс: повноекранний на телефоні та двоколонковий на ноутбуці;
- тепла мінімалістична стилістика без симулятора пристрою.

## Локальний запуск

```bash
npm ci
npm run dev
```

Для перевірки фінальної збірки:

```bash
npm run build
```

## Медична межа

Це навчальний матеріал. Він не замінює локальний клінічний протокол, інструкцію конкретного апарата, консультацію нефролога або рішення відповідальної клінічної команди.
